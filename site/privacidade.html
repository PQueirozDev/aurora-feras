Privacidade

Aurora não coleta nenhum dado pessoal. O jogo não tem cadastro, não usa cookies de rastreamento e não envia informações para servidores.

O progresso é salvo apenas no seu aparelho, no armazenamento local do navegador ou do aplicativo. Para apagar, limpe os dados do site no navegador ou desinstale o aplicativo.

Este site é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso, como o endereço IP, conforme a política de privacidade do GitHub.
